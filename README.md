# Architecture Website

React + Vite + Tailwind CSS + React Router.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Structure
Detail ke liye [docs/STRUCTURE.md](docs/STRUCTURE.md) padhein.
Short me: Navbar ka har link `src/pages/<name>/` folder hai, aur uske parts `sections/` me.
